# Release 3.2

Adds configurable controller keyboard bindings to the HD client.

- Open **Settings → Control customization → Controller settings → Controller key bindings**.
- Choose a keyboard key for any of the 16 controller buttons or four directional stick inputs.
- Save choices automatically, disable individual inputs, or restore the original defaults.
- Restart the HD game to apply binding changes.
- Fix downward stick directions and release held controller keys when the app pauses or changes cursor mode.

The SD client uses a separate input system; these controller bindings apply to HD mode.

## Installation

Download **2009Scape-HD-3.2-debug.apk** and install it over the existing compatible debug
build. The app retains the package name and signing key used by the previous release,
and the version code increases to **9950002** (`hd-3.2`). Existing app data is retained
when Android accepts it as an update; uninstalling the app removes its data.

This follows the 3.1 source build's packaging: the Java runtime is not bundled in the APK.
An existing installed runtime is retained; a fresh installation needs a compatible Java 8
runtime imported through the Java settings before playing.

## Verification

The build runs the eight controller mapping and stick-direction unit tests. Release
packaging verifies the APK signature, application ID, version name/code, ARM64 libraries,
client JAR and plugin assets, and supplies a SHA-256 checksum. Physical controller testing
on the AYN Thor remains necessary.
